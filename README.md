
📌 About The Project

DEVCONF-2026 is a modern conference landing page designed for developers, engineers, founders, and technology enthusiasts.

The website includes information about conference speakers, ticket pricing, activities, networking opportunities, and other events happening during the conference.

✨ Features

- 🧭 Modern navigation bar
- 🚀 Hero section with conference introduction
- 🎤 Speaker section with speaker profiles
- 💳 Pricing section with Standard, Pro, and Team plans
- 🧩 Bento-style "Beyond the Talks" section
- 🎨 Modern gradients and visual effects
- 📱 Clean and responsive-style layout
- 🦶 Simple and professional footer

🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts – Inter
- CSS Flexbox
- CSS Grid
- CSS Gradients
- CSS Backdrop Filter
- CSS Hover Effects

🎯 Sections

Hero Section

Introduces DEVCONF-2026 with a conference banner, description, and registration button.

Meet the Speakers

Displays featured speakers along with their tracks and professional information.

Secure Your Spot

Provides three ticket plans:

- Standard — $399
- Pro — $749
- Team — $5,999

Beyond the Talks

Highlights additional conference activities such as:

- Overnight Hackathon
- The Lounge
- Job Board
- Swag Wall
- Networking opportunities

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

Or use VS Code Live Server to run the project locally.
